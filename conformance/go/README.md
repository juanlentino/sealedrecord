# A second reader, from the document alone

This is a second implementation of docs/FORMAT.md in Go, written against the document without reading the JavaScript, using only the standard library (crypto/sha256, crypto/ed25519). It shares an author with the specification and the reference reader. Not reading the JavaScript closes one channel; it does not close the other, which is the author's own model of the format filling a gap the document leaves. So this reader tests whether the document determines behaviour when read by someone who already knows what it means. It does not test whether a stranger reads it the same way. Six places where the document did not determine behaviour were found this way and are now sentences in it; a seventh that both readers agree on because both assume the same thing would not be. `go test ./...` runs it against `../../vectors/`, the same files the reference reader is tested against, and CI runs both.

It is not a package and is not published. Anyone building a reader in another language can start here or from the document; every place this one had to guess became a sentence in FORMAT.md, which is the point.
